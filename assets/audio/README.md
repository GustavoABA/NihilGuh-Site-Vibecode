# Áudio da abertura

A página `/starting/` procura por:

`assets/audio/harpy-hare.mp3`

O arquivo de áudio comercial não é incluído no repositório. Coloque aqui uma cópia que você tenha direito de usar na transmissão.

Para testar a animação sem áudio:

`/starting/?preview=1`

Para calibrar a sincronização:

`/starting/?debug=1`

Controles no modo debug:
- `[` / `]`: offset -/+ 0,1 s
- Shift + `[` / `]`: offset -/+ 1 s
- setas esquerda/direita: buscar -/+ 1 s
- espaço: play/pause
